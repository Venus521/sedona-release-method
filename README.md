# 释放法 · 自走引导

圣多纳释放法的自问自答练习。单文件网页＋一个安卓包，不用注册。网页打开后不联网；安卓包只在查更新时连一下。

## 下载

到 [Releases](https://github.com/Venus521/sedona-release-method/releases) 下：

- 网页版：zip 解压后双击 `index.html`（或者直接把仓库里的 `index.html` 存下来）。
- 安卓版：`ShiFangFa-public.apk`，第一次装要在系统设置里允许一次「未知来源」。

## 用法

进去有四个页签：引导、八节课、工作本、收获本。引导是主流程，写一句目标，照着屏幕上的问句点选项就行，中途关掉，回来接着走。顶栏「外观」里能换配色和中英文。

## 数据

记录都存在本机浏览器里，清浏览器数据会连记录一起清掉。收获本有个导出 TXT，记得偶尔按一下。换设备搬不过去，没有云同步。
